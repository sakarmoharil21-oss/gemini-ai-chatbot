# Gemini AI Chatbot

An AI chatbot built with Python, Streamlit, and the Google Gemini API.

## Features
- Chat interface powered by Streamlit
- Responses generated by Google Gemini
- `check_models.py` lists the Gemini models available to your API key

## Setup

1. Clone the repo:
   ```
   git clone https://github.com/sakarmoharil21-oss/gemini-ai-chatbot.git
   cd gemini-ai-chatbot
   ```
2. Install dependencies:
   ```
   pip install streamlit google-generativeai python-dotenv
   ```
3. Get a free API key from Google AI Studio.
4. Create a `.env` file in the project folder:
   ```
   GEMINI_API_KEY=your_api_key_here
   ```
5. Run the app:
   ```
   streamlit run app.py
   ```

## Note
Never commit your `.env` file. It is already listed in `.gitignore`.
